# 🏓 Top Spin Hub

Top Spin Hub é uma plataforma web desenvolvida com o objetivo de promover o conhecimento sobre o tênis de mesa por meio de conteúdos informativos, quiz interativo e dashboard de desempenho dos usuários.

## 📖 Sobre o Projeto

O projeto foi desenvolvido para unir informação e entretenimento, permitindo que os usuários aprendam sobre a história, regras e curiosidades do tênis de mesa enquanto testam seus conhecimentos através de um quiz.

Além disso, a plataforma registra os resultados obtidos pelos usuários e apresenta estatísticas em uma dashboard personalizada.

---

## 🚀 Funcionalidades

- Cadastro de usuários
- Login e autenticação
- Página inicial com informações sobre tênis de mesa
- Quiz interativo
- Registro de acertos e erros no banco de dados
- Dashboard com estatísticas do usuário
- Armazenamento de dados em banco de dados

## ⚙️ Como Executar o Projeto

### 1. Clone o repositório

```bash
git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
```

### 2. Acesse a pasta do projeto

```bash
cd SEU-REPOSITORIO
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Configure o banco de dados

- Instale e execute o MySQL.
- Crie o banco de dados utilizando o script SQL disponibilizado no projeto.
- Configure as credenciais de acesso ao banco de dados no arquivo de configuração da aplicação.

### 5. Inicie o servidor

```bash
npm start
```

### 6. Acesse a aplicação

Abra o navegador e acesse:

```text
http://localhost:3333
```
